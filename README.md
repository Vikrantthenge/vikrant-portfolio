| Operational Signal      | Analysis                           | Management Decision               |
| ----------------------- | ---------------------------------- | --------------------------------- |
| Demand exceeds capacity | Utilization analysis               | Rebalance workload / add capacity |
| SLA deterioration       | Trend & exception analysis         | Review process stage / vendor     |
| Growing backlog         | Backlog ageing & capacity analysis | Prioritize workload               |
| Excessive overtime      | Workforce analysis                 | Adjust roster coverage            |
| Flight delay risk       | Predictive model                   | Early operational intervention    |
| Revenue variance        | Forecasting                        | Adjust planning assumptions       |
| Emerging safety trend   | Risk monitoring                    | Investigate / corrective action   |
